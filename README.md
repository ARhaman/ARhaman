# Abdulrahman Al-Fakih

**AI for subsurface characterization** — generative and deep learning models applied to well logs, reservoir properties, and geothermal systems.
King Fahd University of Petroleum & Minerals (KFUPM), College of Petroleum Engineering and Geosciences.

Subsurface datasets are incomplete by nature: missing log intervals, sparse core coverage, noisy measurements. I build models that work under those conditions instead of assuming them away.

---

### Focus areas

- Generative models (GANs, diffusion, Transformers) for multidimensional reservoir characterization
- Anomaly and outlier detection in well log data
- Machine learning for geothermal and energy systems
- Reproducible research workflows for petrophysical data

**Stack:** Python · PyTorch · TensorFlow · scikit-learn · NumPy/Pandas · MATLAB · Jupyter
